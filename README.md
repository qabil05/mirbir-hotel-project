# MIRBIR Boutique Hotel & Resort

Next.js + TypeScript + Tailwind CSS hospitality website with Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build
npm start
```

No Docker. No MySQL. Node.js 18+ and npm are enough.

## Pages

Home, Stay, room details, Experience, Dining, Wellness, Journal, Gallery, Location, Book, Plan your stay, Privacy, Terms, 404.
